weekly-update 0.1.0 sample output, captured from a real run in the test mode.

Produced by the six README Quickstart commands after the clone and the cd,
run as written from the repository folder, one after another. Captured once,
outside the tests; no test regenerates it, so details can lag behind the code:

  ./bin/weekly-update --version
  ./bin/weekly-update check
  ./bin/weekly-update auto --dry-run
  ./install.sh --dry-run
  ./install.sh
  ~/.local/share/weekly-update/app/bin/weekly-update status

This is the shimmed demo environment, not a real Mac. The commands ran in the
test mode that tests/test-docs.sh uses: brew, softwareupdate, launchctl,
osascript, defaults, pmset, open, sudo, caffeinate, sw_vers, id and pgrep were
the test doubles in tests/shims, so nothing reached the real Homebrew,
Software Update or launchd. The Dock listed the four example apps from
tests/harness.sh on AC power, the home folder was fresh and empty apart from
the repository copy, that Dock and an empty LaunchAgents folder, and there was
no config file. The login name "tester" and the Homebrew version come from the
test doubles. The doubles hold no Homebrew cask list and no installed casks,
so no app is mapped to a cask ("no index", "No cask found"). The home folder
is shown as ~; nothing else was changed. All six commands exited with status 0
and wrote nothing to standard error.
